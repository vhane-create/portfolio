# ARIA — Finance & Research Assistant

Launch: https://vhane-create.github.io/portfolio/fpa-copilot/aria-live.html

ARIA is an interactive, browser-based finance and company-research demonstration. The source is `aria-live.html`; the portfolio homepage already links to it.

## Current capabilities
- Typed prompts and example questions
- Illustrative financial variance calculations and research responses
- Browser text-to-speech and optional speech recognition, depending on browser permissions/support
- Optional secure AI backend integration; this is **not** a claim that live AI is enabled on GitHub Pages

## Publication checklist
- [x] ARIA HTML application committed to GitHub
- [x] Portfolio homepage links to the application
- [x] Application JavaScript parses successfully
- [x] Embed a compressed version of the approved ARIA portrait directly in `aria-live.html` (no separate image upload required)
- [ ] Verify the embedded portrait renders on the published site
- [ ] Perform a real-browser test of speech, microphone permissions, finance answers, and backend fallback
- [ ] Verify the live backend is deployed and configured before describing ARIA as connected to live AI

All demonstration finance figures are illustrative. Do not upload private company or personal financial information to an unverified backend.
