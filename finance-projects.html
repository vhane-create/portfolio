02 · SQL project

From transactions to financial insight.

Seven simulated transactions and four budget lines become a reconciled category report, a profit comparison, and a ranked view of unfavorable contributors.

Aggregate, then joinGroup transactions by month and category before joining to budget, avoiding duplicated plan values.
Keep missing data visibleRetain keys from both sources and flag missing actuals or budgets. Keep explicit zero amounts valid.
Rank adverse contributionsUse DENSE_RANK and partitioned SUM to show which categories contribute most to the shortfall.

Includes setup, analysis, diagnostic SQL, instructions, and baseline CSV outputs. Runs in SQLite 3.25+.

WITH actuals AS (
  SELECT month, category_id,
         SUM(amount) AS actual
  FROM transactions
  GROUP BY month, category_id
)
-- Aggregate first; then join to plan.
SELECT b.month, c.category_name,
       b.amount AS budget,
       a.actual,
       a.actual - b.amount AS variance
FROM budgets b
JOIN categories c
  ON c.category_id = b.category_id
LEFT JOIN actuals a
  ON a.month = b.month
 AND a.category_id = b.category_id;
